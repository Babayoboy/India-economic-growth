# India Economic Growth

An analysis of India's economic growth, covering GDP trends and the prime ministers in office from 1960 to 2026. The project combines data processing, SQL-based transformations, and a Power BI dashboard, with a written project report.

## Contents

| File | Description |
|------|-------------|
| `GDP.csv` | GDP data used for the analysis |
| `indian_pm_by_year_1960_2026.csv` | List of Indian prime ministers by year, 1960 to 2026 |
| `data_work.py` | Python script for data cleaning and preparation |
| `changes in gdpn.sql` | SQL script for GDP-related data transformations |
| `changes in gdpr.sql` | SQL script for GDP-related data transformations |
| `India_economic.pbix` | Power BI dashboard file |
| `India_economic.pdf` | Exported PDF of the dashboard |
| `India_Economic_Project_Report.pdf` | Full written project report |

## Tools Used

- Python (data preparation)
- SQL (data transformation)
- Power BI (visualization and dashboard)
